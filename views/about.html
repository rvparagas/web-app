About

What is this?

CPS630 Blog is a multi-page web application built for Assignment 1 of CPS630 Web Application Development at Toronto Metropolitan University. It demonstrates a basic client-server architecture using Node.js, Express, and a REST API.

How it works

The app runs on a Node.js server using the Express framework. Posts are stored in a JSON file on the server. The front end communicates with the server through three API endpoints:

  • GET /api/notes - fetch all posts
  • POST /api/notes - add a new post
  • DELETE /api/notes/:id - delete a post by ID

Future improvements

This application could be extended in several ways: replacing the JSON file with an exteral database, adding user authentication, rebuilding the front end in React, or supporting rich text editing for posts.
